Read hands-free.

Paste a web address above. The page scrolls by itself. You set the speed and the size.

  1. Paste the address and tap Open.
  2. Tap the round button to start or stop.
  3. Move Speed and Size to adjust.

Some sites do not let other pages show them. Most manga sites do this. If a page stays blank, use the bookmark below. It works on every site.

Bookmark version

On iPad:

  1. Tap Copy code.
  2. In Safari, tap the Share button, then Add to Favorites.
  3. Open your bookmarks. Tap Edit, then tap the new bookmark.
  4. Name it Auto-Scroll. Delete the address and paste the code.
  5. On a manga page, tap the address bar, then tap Auto-Scroll.

On a computer: drag the dashed button to your bookmarks bar.
